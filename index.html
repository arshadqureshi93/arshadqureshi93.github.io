Contributions to Frappe Framework

fix(list_view): prevent filters from populating read-only fields

frappe/frappe #35771
✓ Merged

Fixed a bug where creating a new document from a filtered list view would incorrectly overwrite read-only fields' default values with the active filter values.

⚡

fix(workspace): show role-restricted non-public workspaces in sidebar

frappe/frappe #36829
✓ Merged

Fixed visibility logic for non-public workspaces with assigned roles. Role-restricted workspaces were not shown to users with matching roles due to incomplete visibility conditions.

frappe/erpnext #55247
✓ Merged

Fixed Purchase Receipt mapper to respect over-delivery/receipt allowance from Item master. Fully-received PO lines with remaining tolerance now appear in mapped PR, and quantities pre-fill up to the allowance limit.
